# MasterHUB protocol evidence

The table lists implemented capabilities, offline test coverage, and remaining hardware validation. Protocol details derived from the Windows software have not yet been verified on a physical device.

| Capability | Reference or implementation | Offline evidence | Hardware status |
| --- | --- | --- | --- |
| Neutral HID inventory and exact-path open | SDK `DeviceRegistry`; HIDAPI enumeration | Identity matching and stale-selection tests; source review of no-initialization path | Pending |
| Module PID generations | `ModuleKind`, `Module::accepts_product_id`, typed handle selection; base `01f6`/`9999`, knobs `0202`/`9996`, dial `0206`/`9994`, keys `01fe`/`9997`, faders `0200`/`9991`, rollers `0204`/`9995` with VID `2516` | Version-pinned source evidence and tests for aliases, wrong vendor, unsupported IDs, and custom module overrides | Pending |
| Serial feature response | `CanGetSerialNumber`, report `30` for M0 models and `4a` for M131E | Header/ID/length/padding tests and fake transport; actual received length used | Pending |
| M131E software/hardware mode | `dial::software_mode_report`, explicit transport/typed-handle methods; `03 49 <bool>`, 32 bytes total | Exact construction and fake writer tests; explicit lifecycle transitions | Software and hardware mode switch worked on a real unit, 8 Oct 2026 ([results](masterhub-hardware-results.md#m131e-dial)) |
| M131E backlight and solid color | `dial` builders/setters; `03 44 <0..100>` and `03 46 <three channel bytes>` | Bounds validation before writes, zero-padding policy, fake transport failures | Verified on a real unit, 8 Oct 2026: RGB channel order, visible backlight effect, read-back ([results](masterhub-hardware-results.md#m131e-dial)) |
| M131E feature queries | Backlight ID `4c`; firmware selectors `47`, `48`, `49`; bounded reply parsers | Actual returned count, ID and required offsets checked; reply byte 1 remains opaque; firmware bytes preserved without inferred meanings | Firmware text and backlight read back in software mode, 8 Oct 2026; one failed query in hardware mode ([results](masterhub-hardware-results.md#m131e-dial)) |
| M0 raw input frame | Probe `src/m0.rs`: ID `01`, tag `2a`, little-endian length, payload at offset 4 | Pure framing tests including truncated headers/payloads and outer padding | Pending |
| M003K rotation | Probe channel-0 logical payload `00 03` plus three direction bytes | Synthetic reports; `00` counterclockwise, `01` clockwise, `ff` unchanged | Verified on hardware, 8 Oct 2026 ([results](masterhub-hardware-results.md#m003k-knobs)) |
| M003K press/release | Probe logical payload `03 03` plus three states | Synthetic state transitions, simultaneous controls, malformed/unknown state preservation | Verified on hardware, 8 Oct 2026 ([results](masterhub-hardware-results.md#m003k-knobs)) |
| M4315 key input | Native queue-0 frame `01 34 u16LE length`; 15-state snapshot, selectors `02` and legacy `00` | Native/renderer/probe evidence; transitions, duplicates, all controls, malformed state preservation and reset | Physical order, complete reports and startup pending |
| M005S fader input | M0 frame, logical `02 05` plus five positions 0–100 | Native/renderer/probe evidence; initial positions, changed-only events, endpoints, reset and invalid value checks | Physical range, jitter and startup pending |
| M032LE roller input | M0 frame, logical `01 02`; `00` Up, `01` Down, `ff` idle | Native/renderer/probe evidence; simultaneous/repeated directions, no invented magnitude, unknown/malformed preservation | Not observed: no reports on a real unit ([results](masterhub-hardware-results.md#m032le-rollers-unresolved)) |
| M4315 software mode | `keypad::software_mode_report` and explicit setter; `03 3a <bool>`, 32 bytes | Native true/false construction, fake writer failures, CLI identity routing and failed-enable cleanup | Pending |
| Value-aware fader binding | `volume_from_position` → concrete `set_volume`; position/max retained | Strict profile/event validation, no unresolved marker dispatch, mock native setter and simulated live queue tests | Actual audio/device response pending |
| Other input channels/report IDs | Documented but not mapped to knob actions; channel 3 has a different layout | Raw unknown retention | Pending |
| M131E input | `parse_m131e_report`, `parse_m131e_payload`, `M131EDecoder`; queue-0 raw `01 44 u16LE length` | Static SDK/addon/source trace; bounds, application RIGHT/LEFT labels, legacy selectors, duplicate press filtering, repeated rotations, unknown retention and state preservation tested | Payload and direction verified on a real unit, 8 Oct 2026; long press not exercised ([results](masterhub-hardware-results.md#m131e-dial)) |
| M131E host gestures | `DialGestureTracker`, 600 ms long-press threshold from app policy | Fake monotonic timestamps, exact threshold, duplicate presses, unmatched release, backward time and reset | Physical sequences pending; gesture is not a firmware event |
| Knob, fader and base LEDs | `lighting::{color,brightness,mode}_report`, `set_*`; output report ID `02`, command `2d` colour, `2e` brightness, `2c` mode, then module type (`0` base, `1` knobs, `2` faders), LED index and values; sizes from the descriptor | Static disassembly of `Adjust_LED_*_CM_M0` and its call sites in the official addon (see [additional modules](research/masterhub-additional-modules-1.0.0.113.md#led-commands-knobs-faders-base)); exact bytes, index ranges, value limits, padding and short-write tests on a fake transport | Base verified on a real unit, 11 Oct 2026 (mode 1 plus `ff0000` gave a solid red strip). Knob and fader modules ignored every write, so their command set is unresolved ([results](masterhub-hardware-results.md#knob-fader-and-base-leds-11-october-2026)) |
| HID output report sizing | Pure `descriptor::output_report_length`; selected-interface query through `ReportTransport` | Multiple report IDs, constant padding, split fields, push/pop, malformed descriptors and bounded lengths tested; no guessed fallback | Actual descriptors pending |
| M131E display | `JpegPackets`, explicit `display_jpeg`; 240×240 baseline JFIF JPEG; `02 45`, sequence/length, final flag, payload offset 8 | Static source trace; real encoder-generated image fixture; packet reassembly, bounds, zero-fill policy and short-write stop tested; typed upload uses descriptor-derived size | Acceptance, orientation (rotate 0), color order and pacing verified on a real unit, 8 Oct 2026 ([results](masterhub-hardware-results.md#m131e-dial)); rotations other than 0 untested |
| M4315 display packet planning | `keypad::JpegPackets`; 72×72 baseline JFIF JPEG; `02 36`, 16-bit sequence/length, key index 0–14 in byte 6, final flag, payload offset 8 | Native SDK header and pinned renderer evidence; generated image reconstruction, key/report/image bounds, sequence overflow prevention and fresh zero padding tested; CLI uses a saved descriptor without opening hardware | Live upload API, key order, mode, pacing, orientation and acceptance pending |
| Offline image preparation | CLI `dial prepare-image` and `keypad prepare-image`; static PNG/JPEG to 240×240 or 72×72 RGB baseline JFIF with fit, matte, quality and explicit rotation | Entropy-decoded output, crop/orientation/alpha, limits/APNG/corruption, exact packet reassembly and no-overwrite preflight tested | Physical display orientation, color and image acceptance pending |
| Explicit dial lifecycle | `DialSession`: activate/suspend/resume/advance/shutdown; caller supplies notifications and time | Fake transport mode writes, idempotence, two-second resume policy, failures and decoder reset | Requires physical acceptance; `DialSession` itself has no macOS observer or reconnect (the desktop app's session manager supplies them, see next row) |
| Desktop sleep/wake and reconnect | OpenStreamHub session manager (`src-tauri/src/session.rs`, `power.rs`): stops supervised services before sleep, restarts after wake, backs off on crashes and device removal; executing sessions wait for user confirmation | Fake runner/clock state-machine tests, parallel-stop and backoff tests; see [session manager](masterhub-session-manager.md) | Real sleep/wake, replug and mode restoration pending physical acceptance |
| Dial diagnostic commands | Identity-routed replay, default feature previews, offline JPEG plans; live writes require an exact path | Synthetic aliases/events/gestures; complete feature bytes; 31-packet JPEG reconstruction; no-overwrite/preflight; failed enable/footer cleanup tests | Live queries, writes and cleanup require physical acceptance |
| Mac shortcuts/volume/profiles | `cooltek-sdk-service` and `masterhub-service`; strict profiles, serial precedence, output volume/mute, shortcuts, app launch; independently normalized input with bounded work/logging | Synthetic plans, blocked-action/burst tests, gesture timing, overflow, pipe deadlines, subprocess cancellation and finite cleanup; exact audio restore helpers; limited live host observations in the [smoke guide](masterhub-macos-smoke.md) | Physical input, complete macOS effects/permissions, sustained throughput and HID buffering pending |
